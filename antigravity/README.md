# Antigravity kit: engagement invitation

1. Create the project folder, copy `PROJECT.md` into its root (and into Antigravity Rules if available).
2. Put your assets in `public/assets/` (photo, music, video can come later).
3. For each phase: open `phases/NN-*.md`, paste the **Prompt** block to the agent, review the plan, approve, then check the **Definition of done**.
4. Commit after every phase.

## Order
| Phase | File | Result |
|---|---|---|
| 0 | 00-foundation.md | Project, tokens, RTL, empty components |
| 1 | 01-envelope.md | Envelope intro moment |
| 2 | 02-hero.md | Hero, photo frame, names, countdown |
| 3 | 03-story.md | Scroll timeline |
| 4 | 04-event-details.md | Venue, map, calendar |
| 5 | 05-messages-admin.md | Guest messages + /admin |
| 6 | 06-media.md | Music, sfx, video, gallery |
| 7 | 07-polish-performance.md | Preloader, particles, lite mode, OG |
| 8 | 08-deploy-testing.md | Vercel + test checklist |

## If time is short
Do 0, 1, 2, 4, 5, 8 first. Then 3, 6, 7.
